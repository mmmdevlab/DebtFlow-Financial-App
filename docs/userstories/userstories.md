# User Stories

## 1. Authentication & Access

**User Registration:**

- As a user, I want to register for an account so that I can securely store and access my private financial data.

**Secure Login:**

- As a user, I want to log in using my credentials so that my personal debt records remain protected.

**Session Security:**

- As a user, I want my session to automatically expire after 24 hours to ensure my data remains secure even if I leave the app open.

**Data Ownership:**

- As a user, I want to be the sole owner of my records, ensuring that I only see and interact with debt data associated with my account.

## 2. Debt Management

**Categorized Entry:**

- As a user, I want to create debt entries specifically as a Credit Card, Mortgage, or Loan to keep my liabilities organized.

**Detailed Parameters:**

- As a user, I want to input the principal amount, creditor name, interest rate, and due date so the system can accurately model my debt.

**Record Modification:**

- As a user, I want to edit debt details if the terms change (e.g., interest rate hikes or deadline extensions) or to correct input errors.

**Debt Deletion:**

- As a user, I want to delete a debt entry if it was created in error or is no longer relevant to my tracking.

## 3. Repayment Tracking

**Log Payment:**

- As a user, I want to record a payment against a specific debt so that the system automatically subtracts it from my outstanding balance in real-time.

**Payment History:**
As a user, I want a full chronological log of all payments made per debt entry to verify my repayment progress.

**Payment Correction:**

- As a user, I want to edit or delete specific payment entries to maintain the accuracy of my balance.

## 4. Smart Dashboard (The "Visibility" Layer)

**Total Exposure:**

- As a user, I want my Total Outstanding Debt displayed prominently so I have immediate clarity on my total financial liability.

**Upcoming Obligations:**

- As a user, I want a list of payments due within the next 30 days so I can plan my monthly cash flow.

### Visual Urgency Flags:

    **Overdue:**
    - As a user, I want overdue debts flagged in Red for immediate prioritization.

    **Due Soon:**
    - As a user, I want debts due within the next 3 days flagged visually so I can make immediate payment plans.

**Progress Motivation:**

- As a user, I want to see a visual Progress Bar for each debt (e.g., "45% Paid") to stay motivated as I reach my goals.

## 5. Insights (The "Analysis" Layer)

**Overall Progress:**

- As a user, I want to see a visual summary of my overall payment progress in relation to the total debt I have ever held.

**Categorized Breakdown:**

- As a user, I want to see individual types of debts visually identifiable (e.g., a pie chart) with categorized information for each debt type.
