# User Stories

## 1. Authentication & Access

**User Registration:**

- As a user, I want to register for an account so that I can securely store and access my private financial data.

**Secure Login:**

- As a user, I want to log in using my credentials so that my personal debt records remain protected.

**Session Persistence:**

- As a user, I want my session to persist after logging in so that I do not have to re-authenticate every time I open the app.

**Data Ownership:**

- As a user, I want to be the sole owner of my records so that I only see and interact with debt data associated with my account.

## 2. Debt Management

**Categorized Entry:**

- As a user, I want to create debt entries categorized as Credit Card, Mortgage, or Loan so that my liabilities stay organized by type.

**Detailed Parameters:**

- As a user, I want to input the principal amount, creditor name, interest rate, and due date so that the system can accurately model my debt over time.

**Record Modification:**

- As a user, I want to edit an existing debt entry so that I can update terms if they change (e.g., interest rate hikes or deadline extensions) or correct input errors.

**Debt Deletion:**

- As a user, I want to delete a debt entry so that I can remove records created in error or debts that are no longer relevant.

## 3. Repayment Tracking

**Log Payment:**

- As a user, I want to record a payment against a specific debt so that the system automatically subtracts it from my outstanding balance.

**Payment History:**

- As a user, I want a full chronological log of all payments made per debt entry so that I can verify my repayment progress over time.

**Payment Correction:**

- As a user, I want to edit or delete a specific payment entry so that I can maintain the accuracy of my outstanding balance.

## 4. Dashboard

**Total Exposure:**

- As a user, I want my Total Outstanding Debt displayed prominently on the home screen so that I have immediate clarity on my full financial liability.

**Upcoming Obligations:**

- As a user, I want a list of payments due within the next 30 days so that I can plan my monthly cash flow and avoid missed payments.

**Overdue Flag:**

- As a user, I want overdue debts highlighted in red so that I can immediately identify and prioritise them.

**Due Soon Flag:**

- As a user, I want debts due within the next 3 days flagged visually so that I can act before a late fee is triggered.

**Repayment Progress:**

- As a user, I want to see a progress bar for each debt (e.g., "45% Paid") so that I stay motivated as I work toward being debt-free.

## 5. Insights

**Overall Progress:**

- As a user, I want to see a visual summary of my overall repayment progress relative to my total debt so that I can understand how far I have come.

**Categorized Breakdown:**

- As a user, I want a chart breaking down my debt by category (Credit Card, Mortgage, Loan) so that I can identify which debt type represents my largest liability.

# Stretch Goal User Stories

## Notifications & Reminders

**Payment Reminder:**

- As a user, I want to receive an email or push notification before a payment is due so that I never miss a deadline.

**Overdue Alert:**

- As a user, I want to be notified immediately when a debt becomes overdue so that I can take action to avoid late fees.

## Attachments

**Receipt Upload:**

- As a user, I want to attach a receipt or invoice image to a payment entry so that I have a full paper trail of what was paid.

## Reporting & Export

**CSV Export:**

- As a user, I want to export my full debt and payment history as a CSV so that I can use it in external tools like Excel.

**PDF Export:**

- As a user, I want to export a summary of my debts as a PDF so that I can share it with a financial advisor or keep it as a record.

## Extended Insights

**3-Month Outlook:**

- As a user, I want to view a 3-month payment forecast so that I can plan my cash flow further ahead than a single month.

**Debt Payoff Projection:**

- As a user, I want to see a projected payoff date for each debt based on my current repayment pace so that I can set realistic financial goals.

## Multi-Currency

**Currency Selection:**

- As a user, I want to set a preferred currency for my account so that all debt figures are displayed in the currency I use day-to-day.

## Business Accounts

**Invoice Tracking:**

- As a business user, I want to log unpaid invoices as debt entries so that I can track what I owe suppliers alongside my other liabilities.

**Multi-User View:**

- As a business owner, I want to invite a team member to view (but not edit) debt records so that my accountant can access the data they need.
